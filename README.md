# Озёра Андорры

Сайт о пеших маршрутах к горным озёрам Андорры и приграничья Франции и Испании.
Карта в стиле старой туристической схемы. Клик по озеру открывает фотографии, ссылки на Google Maps и маршрут Komoot.

Адрес сайта: **https://nickj-maker.github.io/Andorra-lakes/**

---

## Как добавить новое озеро

1. Откройте папку **`lakes`** и создайте в ней подпапку. Её имя станет названием озера на сайте, например `Estany de Juclar`.
2. Положите в подпапку:
   - **фотографии** в форматах JPG, JPEG, PNG или WEBP. Размер и поворот можно не менять, сайт всё сделает сам;
   - текстовый файл **`points on the map.txt`** с тремя ссылками:

     ```
     start point: https://maps.app.goo.gl/...   ← начало маршрута (парковка и т. п.)
     end point: https://maps.app.goo.gl/...     ← само озеро
     route: https://www.komoot.com/tour/...     ← маршрут в Komoot
     ```

3. Дважды щёлкните **`publish.bat`** в корне проекта.
4. Через 2–5 минут на карте появится новая точка, а в списке — новая строка.

По ссылке `end point` положение озера на карте определяется автоматически.

Перед отправкой `publish.bat` сам удаляет из фотографий GPS-координаты места съёмки. Качество фото не меняется, дата съёмки сохраняется. Для этого на компьютере нужен [Node.js](https://nodejs.org) (версия LTS). Фото в формате HEIC нужно сохранить как JPEG: из HEIC координаты не удалить, и публикация остановится.

**Изменить озеро:** поменяйте фото или ссылки в его подпапке и запустите `publish.bat`.
**Удалить озеро:** удалите подпапку и запустите `publish.bat`.
**Черновик:** подпапка, название которой начинается с `_` (например, `_Estany nou`), на сайт не попадает.

### Дополнительные строки в `points on the map.txt` (по желанию)

```
coords: 42.6034, 1.5712    ← координаты озера вручную, если точка встала не туда
label: left                ← с какой стороны от точки писать название: left / right / top / bottom
cover: IMG_7295.JPEG       ← какое фото показывать обложкой (по умолчанию — первое)
```

### Если что-то пошло не так

`publish.bat` перед отправкой проверяет все озёра и пишет предупреждения, например:

```
⚠ Estany de Juclar
    – нет координат — озеро будет в списке с пометкой «нет на карте». Добавьте в txt строку вида «coords: 42.6034, 1.5712»
```

Одно проблемное озеро не ломает сайт: остальные опубликуются как обычно.
Ход публикации на GitHub: https://github.com/nickJ-maker/Andorra-lakes/actions (зелёная галочка — готово).

## Для разработчика

Нужен Node.js 20+. Установка: `npm install`.

| Команда | Что делает |
|---|---|
| `npm run dev` | локальный просмотр на http://localhost:8080 с пересборкой при изменениях |
| `npm run build` | сборка сайта в `dist/` |
| `npm run strip-gps` | удаление GPS из оригиналов фото в `lakes/` (JPEG, PNG, WebP; без пересжатия) |
| `npm run map:data` | разовая загрузка геоданных OpenStreetMap → `map/data/geo.json` |
| `npm run map:relief` | разовая подготовка подложки рельефа из Copernicus DEM → `map/relief.webp` |

Структура:

- `lakes/` — контент: одна подпапка на озеро;
- `site/` — страница: `index.html`, `style.css`, `app.js`, без фреймворков;
- `scripts/` — сборка: разбор папок, координаты, обработка фото, данные карты;
- `map/` — подложка рельефа, геоданные и `config.json` (подписи населённых пунктов, вершин, рек, область карты по умолчанию);
- `data/geocache.json` — кэш координат, полученных из коротких ссылок Google Maps. Коммитится, чтобы ссылки не раскрывались повторно;
- `.github/workflows/deploy.yml` — сборка и публикация на GitHub Pages при каждом push в `main`.

Область подложки: 42.30–42.85° с. ш., 1.20–2.00° в. д. Если озеро окажется за её пределами, сборка выдаст предупреждение. Тогда нужно расширить `EXTENT` в `map/prepare/relief.js` и `BBOX` в `map/prepare/fetch-osm.js` и заново выполнить `map:data` и `map:relief`.

Источники данных: рельеф — Copernicus DEM GLO-30 (© DLR e.V., © Airbus Defence and Space GmbH, программа Copernicus ЕС/ЕКА); картографические данные — © участники OpenStreetMap (ODbL).
